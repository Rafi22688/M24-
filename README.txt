M24 — FINAL MOBILE PURPLE + WHITE GLASS FRONT-END

Upload these three files exactly as they are:
- index.html
- style.css
- script.js

No code editing is needed for the visual front-end preview.

GitHub Pages:
1. Create a new repository named M24.
2. Upload index.html, style.css and script.js to the repository root (not inside another folder).
3. Open Settings → Pages.
4. Select Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for the published website link and open it on your phone.

This package is a ready-to-publish visual prototype. It includes the responsive mobile UI, purple/white glass styling, search, category filtering, recommendation cards, and a vertically scrolling 16:9 video feed.

Not connected yet: real video playback, Google authentication, user accounts, uploads/cloud storage, creator dashboard, recommendations based on watch history, and monetization. These require a secure backend and service configuration; they cannot be made active by front-end HTML/CSS/JS alone. Do not collect Gmail passwords directly. Use official Google sign-in. Only publish media you own or have permission to distribute.
